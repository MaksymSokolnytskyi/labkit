# labkit

Набір інструментів для дослідницької роботи в Jupyter: журнал прогонів, риштування
проєкту, нотатки в Obsidian.

**Стан: у розробці.** Поки тут лише цей файл. Вміст з'явиться найближчими днями.

## Що це буде

**`record` — журнал прогону.** Одна метрика = один рядок у звичайному текстовому файлі,
який можна прочитати очима і знайти пошуком. Більше не треба переганяти експеримент
заново, щоб згадати число, яке ти вже бачила.

```python
from labkit import record

run = record.start("baseline", params={"alpha": 2.2})
run.metric("score", 0.834)
run.note("artifacts", "видно в темних ділянках")
run.done()
```

**Плагін для Claude Code.** Команда `/labkit:bootstrap` огляне проєкт, поставить кілька
питань і **покаже**, що пропонує зробити, перш ніж щось робити. Нічого не змінюється
без твого «так».
